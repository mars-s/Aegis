# Plan it

- A **plan** with steps in time order: when as the person would say it (Mon, Week 2, 9:00), kind for each step, a detail only where it helps, place and cost when they matter. checkable true when the person will tick steps off.
- A **reply** with the shape of the plan in one sentence and the one thing to do first.
- A **list** of todo items only for things without a time.
- On a follow-up, revise the plan instead of making a new one.
