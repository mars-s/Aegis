# Analyse data

## Look first
- Read the board. Find the data: sheet objects, tables pasted into notes, numbers in cards. Name the columns and their types before you chart anything.
- Decide the two or three questions the data can actually answer (what changed, what is biggest, how parts compare). Ask nothing the data cannot answer.

## Result
- **reply**: the main finding as the headline ("Thursday was the busiest day"), one or two sentences on why it matters, figures for the key numbers.
- One **plot** per question. Choose the style for the question: bar for comparing categories, line or area for change over time, area_stacked or bar_stacked for parts of a whole over time, donut only for a few shares of one total, radar for comparing a few options on several measures.
- A **sheet** of the cleaned data or the summary table, with best marked on the columns where one value wins, so the person can sort it.
- Values come from the data on the board. Write basis as where they came from ("From the Week by day sheet"). Never invent values; a gap is null.
- When the person asks a follow-up (filter, split, compare another column), revise the existing objects instead of adding new ones.
