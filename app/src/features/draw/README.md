# Drawing port

G1 to G9 are registered through the feature registry. Drawing geometry is adapted from the MIT source named in the file headers. Stamps use system Unicode emoji only. No stamp images, fonts or character assets are loaded.

- P opens freehand drawing. Pen tapers with speed, marker stays even and highlighter is translucent. Each tool remembers its own thickness. The nonlinear slider, arrow keys, wheel and square brackets adjust thickness. The eraser has a screen-sized ring and removes complete ink strokes, including rotated or resized strokes. Ink cards store local timestamped `props.points` with `ow`, `oh`, `pen`, `size` and `ink`.
- S opens shapes. Rectangle, ellipse, triangle, diamond, star, heart, arrow and hexagon can contain text. Solid, dashed, dotted and no-border outlines, dash length/gap, fill, no fill, thickness and corner radius are editable. No fill restores an outline when needed. Legacy boolean dash cards remain supported. These outline controls also apply to paths. Lines have straight, wavy, zigzag and loopy styles, tightness, roundness, wobble and height. A line under 24 px keeps the board's minimum hit box and stores its visual height in `props.lineHeight`.
- Shift+P opens the vector Pen. Click to place points, drag to create handles, Shift to snap to 45 degrees, Option for a one-sided handle. Click the first point to close. Enter, Escape, double-click or changing tools finishes an open path. Backspace removes the last draft point.
- Double-click a path or supported shape outline to edit points. Shift-click selects multiple points. Drag points or handles, Option-drag pulls handles, double-click a point switches sharp and smooth. Click the outline to insert a point without changing its curve. Delete removes selected points when at least two remain. Corners and the inner radius dot round sharp corners. Enter, Escape or clicking away finishes. Conversion to a path preserves the card id, text, stacking and connector ids/styles through one atomic command batch. Hearts and standalone lines retain their own geometry, as in the source.
- E opens emoji stamps. The wheel holds eight favourites. The full picker and recent list use real emoji. Picking a new emoji in the full list prepends it to the eight favourites, as in the source. Repeat picks keep the favourite order. Every pick updates the twelve recents immediately, before placement. Both lists survive reload. Placement repeats until Escape, right-click or changing tools. Stamps resize as squares and offer optional motion that respects reduced-motion settings. Preferences use `aegis:draw`.
- Hover or select a card and drag an edge knob onto another card. Click a connector's wide SVG hit area to select it. Drag the middle handle to bend, or an endpoint onto a different card to reconnect. Controls offer straight/curved, solid/dashed, none/end/both arrows, colour, label, flip, auto ends and deletion. Duplicate undirected pairs are refused during drawing or reattachment. Labels are an Aegis addition requested in the task.

Shared additions are `linkGeometry()` and `drawLinks()` rendering/hit areas in the engine, `link_update` with validated optional fields/removal, optional stable `connect.newId`, link ids/styles in `describe()`, and one import in each feature/type entrypoint. All drawing and pointer behaviour stays in this feature.

Checks: `node --test agent/checks/draw.test.mjs`, `npm --prefix agent run check`, and `cd app && npx svelte-check --threshold error`. The real-browser check is `checks/ui/draw.mjs`, using Vite port 5182, a fake-model host and temporary data.

## Drawing gap verification

`checks/ui/draw.mjs` exercises solid/dashed/dotted/no-border SVG output on both shapes and paths, custom dash length/gap, restoring an outline for no fill, saved styles after reload, and full-picker favourites/recents before placement and after reload. It uses port 5182 with a temporary fake-model host and disabled file watching, so concurrent feature edits cannot interrupt gestures.
